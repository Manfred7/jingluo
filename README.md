# Каналы (jingluo)

Тренажёр каналов и точек акупунктуры: найти точку на фигуре, узнать её канал и название. 14 каналов, 218 точек.
Эталон — «Основы китайской медицины» Дж. Мачоча (коды L.I.-4, T.B., G.B., LIV, Ren, Du; названия кириллицей);
места точек — по описаниям стандарта ВОЗ 2008. Задание — [TZ.md](TZ.md).

**Открыть:** https://manfred7.github.io/jingluo/

Учебный тренажёр для запоминания мест и названий точек. Не медицинская рекомендация и не руководство к лечению.
Фигуры — свои схематичные рисунки; места точек сверены с открытыми источниками ([docs/verify-points.md](docs/verify-points.md)),
сверка с книгой Мачоча ещё впереди.

## Установка на телефон

Отдельно скачивать ничего не нужно: приложение ставится прямо с сайта, открывается без адресной строки и работает без интернета.

**Android (Chrome)**
1. Откройте https://manfred7.github.io/jingluo/ в Chrome.
2. Внизу стартового экрана нажмите «Установить на устройство». Если кнопки нет — меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Подтвердите — на главном экране появится значок 經絡 «Каналы».

**iPhone / iPad (только Safari)**
1. Откройте ссылку именно в Safari.
2. «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».

**Без интернета и обновления**
- После установки откройте приложение один раз с интернетом — дальше оно работает офлайн.
- Шрифты подписей подгружаются при первом показе; фигуры и точки от шрифтов не зависят.
- Новая версия скачивается сама и включается при следующем открытии с интернетом.
- Прогресс хранится на устройстве: у телефона и компьютера он свой; очистка данных браузера его стирает.

## Режимы

- **Атлас** — канал на фигурах: ход и точки, нажатие на точку открывает карточку (код, название, иероглиф).
  Список каналов группируется: по суточному кругу, по шести уровням (Тай-ян, Ян-мин, Шао-ян, Тай-инь, Шао-инь,
  Цзюэ-инь — пары «рука + нога»), «инь/ян руки и ноги», по пяти стихиям. В шапке канала — полное название
  («Ножной канал желчного пузыря Шао-ян (Малый Ян) 足少陽膽經»).
- **Узнай точку** — маркер на фигуре (или название/код) → выбрать ответ из четырёх. Направления: место → название,
  место → код, название → код, код → название. С ростом уровня неверные варианты всё ближе: соседние номера канала,
  соседние точки на фигуре, точки других каналов рядом, одноимённые точки.
- **Состав** — маркер на фигуре → выбрать канал из 14, затем номер.
- **Узнай канал** — подсвечена линия канала → какой это канал.
- **Уровни** — шесть уровней (六經): канал → уровень, уровень → пара каналов «рука + нога», «ручной канал Шао-ян» → канал.
  На высоком уровне неверные варианты — «полуверные» пары и второй канал того же уровня.
- **Отметь точку** — дано название → нажать на место на фигуре. Засчитывается, если нажатие ближе к верной точке,
  чем к соседним, и в пределах допуска; парные точки — с любой стороны.

**Колоды:** 12 точек Ма Даньяна → каналы по суточному кругу → Жэнь-май, Ду-май → все точки. Следующая открывается,
когда в предыдущей освоено 80% точек (точка освоена после трёх верных ответов подряд в любом режиме с точками);
«Открыть все колоды» снимает порог. Прогресс — по системе Лейтнера: слабые точки выпадают чаще, каждая точка колоды
появляется в сессии хотя бы раз. В итогах — рост освоения и «Повторить ошибки».

## Разработка

```bash
npm install
npm run dev       # http://127.0.0.1:5176/
npm run dev:lan   # то же по Wi-Fi для телефона (без установки и офлайна — для них нужен HTTPS)
npm run build && npm run preview   # сборка как на сайте: http://127.0.0.1:4176/jingluo/
```

Публикация — сама: каждый push в `main` собирает сайт и выкладывает на GitHub Pages (`.github/workflows/deploy.yml`).

### Редактор координат

http://127.0.0.1:5176/?edit — только при `npm run dev`, в сайт не попадает. Выбрать вид и канал, перетащить точку
(стрелки — на 1 px, Shift — на 5), «Сохранить» — правки пишутся в `src/data/placements.json` поверх формул.
Пунктирный кружок — место по формуле; «Вернуть по формуле» убирает правку. Запись разрешена только с этого компьютера,
сохранение из второй вкладки поверх чужих правок отклоняется.

### Где что

- `src/data/points.ts` — список точек: строка на канал, `номер Название 漢字` через ` · `.
- `src/figures/*` — виды тела из простых форм, места точек формулами по цуням от ориентиров, ход каналов.
- `src/logic/` — вопросы (`quiz.ts`), проверка нажатия (`hitTest.ts`), прогресс, колоды, выбор вида для точки.
- `src/screens/` — экраны режимов, старт, итоги, атлас.
- Иконка — `npm run icon` (знаки 經絡 контурами из hanzi-writer-data; путь к пакету — аргументом).

Стек: Vite + React + TypeScript, `vite-plugin-pwa`; без бэкенда, прогресс и настройки — в localStorage.
