# Каналы (jingluo)

Тренажёр каналов и точек акупунктуры: найти точку на фигуре, узнать её канал и название. Эталон — «Основы китайской медицины» Дж. Мачоча; задание — [TZ.md](TZ.md).

Пока только локальное веб-приложение, никуда не выкладывается.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://127.0.0.1:5176/.

**С телефона по Wi-Fi** (компьютер и телефон в одной сети):

```bash
npm run dev:lan
```

Vite напечатает адрес вида `http://192.168.x.x:5176/` — открыть его в браузере телефона. При первом запуске Windows спросит, разрешить ли доступ Node.js к сети: нужно разрешить для частных сетей. Установка «на главный экран» и работа без сети в этом режиме не работают — для них нужен HTTPS (вернёмся, если решим публиковать).

## Что есть сейчас (этап 1 — каркас)

- Список 14 каналов со счётчиком точек и список точек канала: код по Мачоча, название кириллицей, иероглиф, код ВОЗ. Список — **черновик**, сверяется с книгой.
- Светлая и тёмная тема.
- Перенесены из sign-trainer / bazi-trainer: прогресс по Лейтнеру (`src/logic/progress.ts`), выбор следующей карточки (`src/logic/session.ts`), тема, шапка сессии.
- Проверка данных при запуске dev-сервера (консоль браузера): порядок номеров, повторы иероглифов, совпадения названий в кириллице.

## Этап 2 — пилот фигур

- Три вида: **тело спереди**, **рука с ладони**, **рука с тыла** (`src/figures/`). Фигуры собраны из простых форм
  (капсулы, эллипсы, гладкие контуры) — свои, без картинок из атласов.
- Точки **LU** и **L.I.** расставлены формулами по цуням от ориентиров (локтевая и запястная складки, ключица, кадык…):
  например, LU-6 — «7 цуней выше LU-9 на линии LU-9 — LU-5». Формулы и комментарии — в файлах видов.
- **Атлас канала:** на экране канала — ход канала и точки на видах, нажатие на точку открывает карточку.

### Редактор координат

Открыть http://127.0.0.1:5176/?edit (только при `npm run dev`). Выбрать вид и канал, перетащить точку на правильное
место (стрелки — на 1 px, Shift — на 5), «Сохранить» — правки пишутся в `src/data/placements.json` поверх формул.
Пунктирный кружок — где точка стоит по формуле; «Вернуть по формуле» убирает правку. Точку, которой нет на виде,
можно выбрать в списке и поставить нажатием на фигуру.

## Как поправить список точек

Точки канала — одна строка в [src/data/points.ts](src/data/points.ts): `номер Название 漢字` через ` · `. Убрать точку — удалить её из строки, добавить — вписать в нужное место по номеру.
